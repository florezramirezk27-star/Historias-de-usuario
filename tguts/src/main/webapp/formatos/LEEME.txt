CARPETA DE DOCUMENTOS DE FORMATOS
=================================

Esta carpeta contiene los documentos base de los formatos oficiales del
proceso de grado:

  - FDC-124-Anteproyecto.pdf  -> Formato de anteproyecto (idea)
  - FDC-125-DocumentoFinal.pdf -> Formato de documento final

La tabla formatos guarda la URL o ruta del documento (columna url) y el
modulo "Formatos de grado" (Administracion o Coordinacion) permite
registrar o actualizar ese enlace. Puede apuntar a un archivo local de
esta carpeta (ruta relativa, como formatos/FDC-124-Anteproyecto.pdf) o a
una URL externa (https://...).

NOTA: al hacer Copy-Item desde src a webapps no se borran los archivos
que ya estan en esta carpeta (la sincronizacion solo sobrescribe).
