# Historias-de-usuario

Sistema de Trabajos de Grado UTS — Proyecto JSP + JSTL (Maven) con base de datos MySQL/MariaDB (XAMPP).

## Contenido

- `tguts/` — Aplicación web (JSP + JSTL) del sistema de trabajos de grado.
  - `src/main/webapp/` — Páginas JSP, CSS e imágenes.
  - `sql/db_tgd_uts.sql` — Script de base de datos.
  - `pom.xml` — Configuración Maven (empaquetado WAR).
